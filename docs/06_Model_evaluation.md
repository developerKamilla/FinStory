# Протокол оценки модели терминов

## Объект проверки
Дообученная модель cointegrated/rut5-base-paraphraser с локальными объединёнными весами. Проверяются пять обученных понятий: дебетовая карта, накопительный счёт, вклад, инвестиция и акция.

## Набор испытаний
Для каждого понятия подготовить по одному сюжету на темы рисования, аниме, архитектуры, кино и спорта: всего 25 сочетаний. Для сравнения со словарём использовать тот же термин и ту же историю.

## Критерии
| Критерий | 0 | 1 | 2 |
|---|---|---|---|
| Финансовый смысл | Определение искажено | Неполно, но без опасной подмены | Основной смысл сохранён |
| Русский язык | Трудно понять или бессмыслица | Понятно, но есть шероховатости | Естественная формулировка |
| Связь с историей | Пример отсутствует или противоречит сюжету | Связь общая или неполная | Пример использует конкретные события без новых фактов |

Ответ проходит проверку при смысле 2, связи 2 и грамотности не ниже 1. Критическую смысловую ошибку отмечать отдельно. Для отчёта указать число оценённых ответов и правила подсчёта. При одном оценщике отметить, кто выполнял оценку; не называть её независимой экспертизой.

## Сравнение со словарём
Словарный вариант и модель оцениваются по тем же критериям. Не менять историю между вариантами и не отбирать только удачные ответы модели. Тексты можно обозначить A и B, чтобы оценщик не знал способ получения. 

## Расчёты
Доля прошедших = число прошедших / число проверенных × 100%.
Доля критических ошибок = число ответов с критической ошибкой / число проверенных × 100%.
Средний балл критерия = сумма баллов критерия / число проверенных.
При нуле проверенных ответов показатели не рассчитываются. Файл 07_Model_review.csv содержит поля для фиксации результатов; пустые оценки не являются нулями.
