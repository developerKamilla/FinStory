# FinStory — 12 уроков по фиксированному плану

Веб-прототип персонализированного обучения финансовой грамотности. Ученик отвечает на вопросы об интересах и знаниях, читает короткие главы, объяснения понятий и отвечает на три вопроса. Порядок 12 тем задаётся `data/lessons.json` и не меняется моделью.

## Запуск

Нужен Python 3.11+. Из папки проекта:

```bash
python -m pip install -r requirements.txt
python web_mvp.py
```

Откройте http://127.0.0.1:8000. Для Windows есть `run_web_windows.bat`; для macOS/Linux — `run_web_mac_linux.sh`.

Для генерации новых глав через Yandex AI Studio задайте на сервере `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. По умолчанию используется Alice AI LLM (`aliceai-llm`); другую модель можно выбрать через `FINSTORY_YANDEX_MODEL`. Ключ не передаётся в браузер и не включён в архив. Без ключа или при отклонении ответа приложение показывает подготовленную главу.

В PowerShell перед `python web_mvp.py`:

```powershell
$env:YANDEX_API_KEY = "ВАШ_КЛЮЧ"
$env:YANDEX_FOLDER_ID = "ID_КАТАЛОГА"
python scripts/inspect_models.py --lesson 3 --interests sport music --with-llm
python web_mvp.py
```

Проверьте в выводе `Источник истории: генерация по плану`. Если показана подготовленная глава, проверьте ключ, ID каталога, доступ к модели и правила проверки главы. `http://127.0.0.1:8000/api/health` показывает, загружены ли собственные модели и заданы ли оба параметра Yandex. Не публикуйте ключ в репозитории или в браузерном JavaScript. Создание проекта в SourceCraft для локального запуска не требуется.

## Что делает каждый компонент

- `models/interest_classifier.joblib`: обученный классификатор распознаёт несколько интересов по тексту и выбору пользователя.
- `models/plot_ranker.joblib`: обученный ранжировщик выбирает подходящие интерес и характер действия из вариантов планирования. Тема, продукт и порядок уроков остаются фиксированными. `src/plan_catalog.py` задаёт проверенные финансовые ограничения и продолжение серии.
- `models/term_ranker.joblib`: обученный ранжировщик выбирает конкретный пример к каждому понятию с учётом интереса. Определение из `data/finance_terms.csv` добавляется без изменения смысла.
- `data/story_contract.txt`: системный промпт агента. Его можно вставить в Yandex AI Studio; веб-сервер отправляет тот же текст через Responses API вместе с выбранным планом. Сохранённый в интерфейсе агент сам по себе не вызывается по имени этим кодом.
- `src/validation.py`: проверка длины, части финансовых чисел и других явных нарушений; при отклонении используется подготовленная глава. Эта проверка не доказывает точность любого нового текста.

Модель ранжирования не пишет финальную прозу. При наличии API текст пишет Alice AI LLM по промпту и плану, выбранному обученной моделью проекта. Микровывод возвращается отдельно. Персонаж остаётся одним на все 12 глав; предыдущая прочитанная глава передаётся при последовательном прохождении.

## Обучение и проверка

```bash
python scripts/train_models.py
python -m unittest discover -s tests -v
```

Обучающие наборы в `data/*_labeled.jsonl` созданы по явно заданным авторским правилам совместимости. Отчёт `evaluation/model_report.json` показывает, насколько точно модели воспроизводят эти метки на отложенных сочетаниях. Такие метки не равны оценкам читателей. Тексты известных книг и комиксов не используются.

В `evaluation/README.md` описано слепое сравнение трёх вариантов: прежний шаблон, навык без планировщика, модели проекта вместе с навыком. Скрипты создают лист оценивания и подсчитывают оценки после работы нескольких людей. Заполнять его фиктивными баллами нельзя. Без ключа API и оценщиков результатов этого сравнения пока нет.
