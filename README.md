# FinStory

Учебный веб-прототип с историями по интересам пользователя. Истории создаёт Yandex AI Studio. Объяснения пяти понятий формирует дообученная ruT5, остальные понятия используют словарь с примером из истории.

## Быстрый запуск
Если зависимости и веса уже установлены, сохрани свой .env и папку models/terms. Положи их в эту копию проекта. В терминале VS Code:

```powershell
conda activate alisa-course
Remove-Item Env:FINSTORY_DEMO -ErrorAction SilentlyContinue
python -u .\app.py --open
```

Терминал должен оставаться открытым. Адрес: http://127.0.0.1:8000. Остановка: Ctrl+C.

## Первая установка
Нужен Python 3.11. Установи зависимости тем же интерпретатором, которым будешь запускать сайт:

```powershell
conda create -n alisa-course python=3.11
conda activate alisa-course
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python setup_model.py .\FinStory_trained_model.zip
python -u .\app.py --open
```

В .env заполни YANDEX_API_KEY и YANDEX_FOLDER_ID. Команда копирования примера нужна только при отсутствии своего .env. Готовый архив модели из Colab устанавливается через setup_model.py без обучения.

В models/adapter находится дообученный адаптер. Если объединённые веса не установлены, загрузчик попробует скачать базовую модель из Hugging Face и подключить адаптер. Для первого такого запуска нужен интернет. Надёжнее использовать уже сохранённые объединённые веса.

## Курс
Один ответ об увлечениях, пять вводных вопросов, десять уроков с одним основным понятием в каждом. Первые три темы: дебетовая карта, накопительный счёт, вклад. Далее: кредит, инфляция, сложный процент, инвестиции, акции, облигации, диверсификация.

После урока есть три вопроса, после уроков 3, 6 и 9 — повторение из семи вопросов. Повторное открытие показывает сохранённый материал. Повторный опрос в профиле сбрасывает прежние главы и прогресс.

## Проверка режима
На /api/status поле mode должно быть yandex. После загрузки модели term_backend меняется на local_merged при использовании models/terms. В журнале data/generated.jsonl отдельно записаны источник истории и источник каждого объяснения. local_merged и trained_adapter обозначают пути обученной модели; dictionary и demo_dictionary — словарь.

Демонстрацию без ключей можно открыть командой python app.py --demo --open. В этом режиме используются подготовленные истории. Он предназначен для проверки интерфейса.

## Проверки
```powershell
python -m unittest discover -s tests -q
```
Тесты проверяют код и взаимодействие компонентов с подменой внешних ответов. Качество живой генерации оценивается отдельно по финансовому смыслу, русскому языку и связи с историей. Модель обучена на пяти понятиях и может ошибаться.

## Файлы
app.py связывает компоненты; agent.py обращается к Yandex; terms.py загружает модель; interests.py вычисляет веса по словам; index.html содержит интерфейс. data хранит учебный материал, docs — отчёт, инструкции, протокол и сценарий демонстрации.

Ключи и пользовательские журналы не загружай в репозиторий. Диагностические метки источника нужны для проверки работы модели.
